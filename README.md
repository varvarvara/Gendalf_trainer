# Gendalf Trainer

**Голосовой ИИ-тренажёр встреч для отдела продаж**  
**LLM Powered Voice Agent for Sales Training**

Gendalf Trainer - прототип голосового тренажёра для обучения менеджеров по продажам. Пользователь ведёт диалог с AI-клиентом голосом: система распознаёт речь менеджера, генерирует ответ клиента через LLM, озвучивает его и после завершения тренировки формирует оценку разговора по критериям качества продаж.

Проект ориентирован на младших сотрудников отдела продаж, которым нужно безопасно отрабатывать встречи, звонки, выявление потребностей, работу с возражениями и завершение разговора на следующий шаг. Косвенные пользователи продукта - руководители отделов продаж, HR-специалисты и компании с большим количеством телефонных или онлайн-продаж.

## Зачем нужен проект

Тренажёр решает три задачи:

- помогает менеджерам регулярно тренироваться перед реальными встречами;
- снижает риск ошибок в коммуникации с клиентами за счёт безопасной симуляции сложных сценариев;
- автоматизирует первичную оценку диалога и даёт рекомендации без постоянного участия наставника.

## Что реализовано

- web-интерфейс тренировки на NiceGUI;
- запуск и остановка голосовой сессии;
- запись речи пользователя через микрофон;
- определение голосовой активности через WebRTC VAD;
- версия с шумоподавлением и нормализацией аудиопотока;
- распознавание русской речи через T-one STT;
- генерация ответа AI-клиента через LLM API;
- озвучивание ответа через Silero TTS;
- возможность перебить AI-клиента во время ответа;
- сохранение контекста диалога внутри сессии;
- транскрибация разговора;
- скачивание транскрипта в `.txt`;
- автоматическая оценка завершённой тренировки;
- детальные баллы по критериям продаж;
- рекомендации по улучшению разговора.

## Пользовательский сценарий

1. Пользователь открывает web-интерфейс.
2. Нажимает кнопку запуска тренировки.
3. Система активирует микрофон и ожидает речь.
4. Менеджер говорит реплику клиенту.
5. Аудио проходит через обработку, VAD и STT.
6. Распознанная реплика отправляется в LLM.
7. LLM отвечает от лица клиента по заданному сценарию.
8. Ответ клиента озвучивается через TTS.
9. После завершения звонка система показывает транскрипт, общий балл, оценки по критериям и рекомендации.

## Архитектура

Основной pipeline работы приложения:

```text
Audio stream
  -> noise reduction / normalization
  -> WebRTC VAD
  -> T-one STT
  -> LLM API
  -> Silero TTS
  -> NiceGUI interface
```

В проекте есть две версии приложения:

```text
main.py                         # базовая версия голосового тренажёра
main_with_noise_suppression.py  # версия с шумоподавлением и улучшенным UI
```

## Критерии оценки

После завершения тренировки LLM анализирует диалог и выставляет оценки по шести блокам:

1. Приветствие и установление контакта.
2. Активное слушание и эмпатия.
3. Выявление потребностей.
4. Презентация решения.
5. Работа с возражениями.
6. Завершение и договорённости.

Каждый критерий оценивается по шкале от 1 до 10. Максимальный результат - 60 баллов. Если сумма больше 40, тренировка считается успешно пройденной.

## Почему T-one и Silero

T-one используется как STT-компонент для русской речи и real-time сценариев, где важна потоковая обработка короткими сегментами. Silero используется для TTS, потому что поддерживает русскую речь, работает локально, не требует GPU и подходит для задач с низкой задержкой озвучивания.

## Структура проекта

```text
.
├── main.py

```

Для полноценной работы рядом с кодом должны быть локальные модели и пакет STT:

```text
T-one/                  # код/пакет STT
models/tone/model.onnx  # модель T-one для версии с noise suppression
models/v5_ru(1).pt      # модель Silero TTS
```

Модели не включены в репозиторий, потому что это тяжёлые локальные артефакты и они зависят от окружения.

## Установка

```bash
git clone https://github.com/varvarvara/Gendalf_trainer.git
cd Gendalf_trainer
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Если `PyAudio` не устанавливается на macOS, сначала установите PortAudio:

```bash
brew install portaudio
pip install pyaudio
```

## Настройка

Скопируйте пример переменных окружения:

```bash
cp .env.example .env
```

Заполните значения:

```env
LLM_API_URL=https://example.com/v1/chat/completions
LLM_API_KEY=your_api_key
LLM_MODEL=qwen3-14b-awq
```

В текущей версии `API_URL` и `API_KEY` также используются в коде как константы. Перед production-использованием их нужно окончательно вынести в `.env`, чтобы не хранить секреты в кодовой базе.

## Ограничения текущей версии

- STT/TTS модели подключаются локально и не хранятся в репозитории;
- API URL и ключ нужно вынести из кода в `.env` полностью;
- нет отдельного backend-сервиса и базы данных для истории тренировок;
- нет авторизации пользователей;
- оценка зависит от качества ответа LLM и корректности JSON-формата;
- для работы нужен микрофон и корректная локальная аудиоконфигурация.
