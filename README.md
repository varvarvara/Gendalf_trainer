# Gendalf Trainer

**Голосовой ИИ-тренажёр встреч для отдела продаж**  
**LLM Powered Voice Agent for Sales Training**

Gendalf Trainer — прототип голосового тренажёра для менеджеров по продажам. Система имитирует разговор с клиентом, принимает голос менеджера через микрофон, распознаёт речь, генерирует ответ AI-клиента, озвучивает его и после завершения тренировки оценивает диалог по критериям качества продаж.

Проект ориентирован на обучение менеджеров встречам и звонкам: приветствие, выявление потребностей, работа с возражениями, презентация решения и закрытие разговора на следующий шаг.

## Возможности

- голосовой диалог менеджера с AI-клиентом;
- автоматическое определение речи через WebRTC VAD;
- распознавание речи через T-one STT pipeline;
- генерация ответов клиента через LLM API;
- озвучивание ответов через Silero TTS;
- режим с шумоподавлением в `main_with_noise_suppression.py`;
- возможность перебить AI-клиента во время ответа;
- финальная оценка диалога по 6 критериям;
- рекомендации по улучшению разговора;
- скачивание транскрибации;
- web-интерфейс на NiceGUI.

## Как работает сценарий

1. Пользователь запускает тренировку.
2. Менеджер говорит в микрофон.
3. Система выделяет речь, сохраняет аудио и отправляет его в STT.
4. Распознанный текст передаётся в LLM.
5. LLM отвечает от лица клиента по заданному сценарию.
6. Ответ клиента озвучивается через TTS.
7. После завершения разговора LLM оценивает диалог и возвращает JSON с баллами и рекомендациями.

## Критерии оценки

Тренажёр оценивает разговор по шести блокам:

1. Приветствие и установление контакта.
2. Активное слушание и эмпатия.
3. Выявление потребностей.
4. Презентация решения.
5. Работа с возражениями.
6. Завершение и договорённости.

Итоговая оценка считается по шкале до 60 баллов. Если сумма больше 40, тренировка считается успешно пройденной.

## Структура проекта

```text
.
├── main.py                         # базовая версия голосового тренажёра
├── main_with_noise_suppression.py  # версия с шумоподавлением и улучшенным UI
├── requirements.txt                # Python-зависимости
├── .env.example                    # шаблон переменных окружения
└── README.md
```

Дополнительно для полноценной работы нужны локальные модели:

```text
T-one/                  # пакет/код STT, если используется main.py
models/tone/model.onnx  # STT-модель для main_with_noise_suppression.py
models/v5_ru(1).pt      # Silero TTS модель
```

Модели не включены в репозиторий, потому что они могут быть тяжёлыми и зависят от локального окружения.

## Установка

### 1. Клонировать репозиторий

```bash
git clone <repo-url>
cd Gendalf_trainer
```

### 2. Создать виртуальное окружение

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

Если PyAudio не устанавливается на macOS, сначала установите PortAudio:

```bash
brew install portaudio
pip install pyaudio
```

### 4. Настроить переменные окружения

```bash
cp .env.example .env
```

Заполните:

```env
LLM_API_URL=https://example.com/v1/chat/completions
LLM_API_KEY=your_api_key
LLM_MODEL=qwen3-14b-awq
```

> В текущей версии API URL и ключ задаются в коде как константы `API_URL` и `API_KEY`. Перед публичным использованием лучше вынести их в `.env`, чтобы не хранить секреты в репозитории.

### 5. Добавить модели

Положите STT/TTS модели в ожидаемые директории:

```text
models/tone/model.onnx
models/v5_ru(1).pt
```

Для базовой версии `main.py` также может потребоваться папка `T-one/` рядом со скриптом.

## Запуск

Базовая версия:

```bash
python main.py
```

Версия с шумоподавлением:

```bash
python main_with_noise_suppression.py
```

После запуска откройте интерфейс в браузере:

```text
http://localhost:8081
```

или для версии с шумоподавлением:

```text
http://localhost:8082
```

## Ограничения текущей версии

- модели STT/TTS подключаются локально и не входят в репозиторий;
- API URL и ключ пока заданы в коде;
- нет отдельного backend-сервиса и базы данных для хранения результатов;
- нет авторизации пользователей;
- оценка зависит от качества LLM-ответа и корректности JSON, который возвращает модель;
- для работы нужен микрофон и локальная аудиоконфигурация.

## Безопасность

Не храните API-ключи, токены и приватные модели в публичном репозитории. Используйте `.env`, секреты GitHub Actions или защищённое хранилище конфигурации.
